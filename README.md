# YouTube Lecture Summarizer with Visual Timeline
YouTube Lecture Summarizer with Visual Timeline
  
A Python tool to generate PDF summaries of YouTube lectures, including screenshots every 20 seconds and summarized transcript segments. This project leverages the YouTube Transcript API, transformer models for summarization, and OpenCV for frame extraction.
Features

Downloads YouTube videos using yt-dlp.
Extracts frames at 20-second intervals using OpenCV.
Fetches and segments transcripts (supports Hindi-to-English translation) using YouTube Transcript API.
Summarizes transcript segments using a transformer model (DistilBART) with batch processing.
Generates a PDF with screenshots and summaries using ReportLab.

Installation
To run this project locally or in Colab, follow these steps:

Clone the repository:
git clone https://github.com/Shyam-Singh-Bhargaw/youtube-lecture-summarizer.git
cd youtube-lecture-summarizer


Install the required dependencies:
pip install -r requirements.txt

Note: If running in Colab, the notebook includes a cell to install dependencies.

The script will download the video, extract frames, fetch and summarize the transcript, and generate a PDF summary.
