📚 YouTube Lecture Summarizer with Visual Timeline 🚀
   
Transform lengthy YouTube lectures into concise, AI-generated PDF summaries with visual timelines!This tool extracts key frames, summarizes transcripts using state-of-the-art NLP models, and compiles everything into a beautifully formatted PDF.Perfect for students, educators, and lifelong learners who want to study smarter. 🎓

🌟 Features

🎥 Video Download: Seamlessly downloads YouTube lectures using yt-dlp.
🖼️ Frame Extraction: Captures video frames every 20 seconds using OpenCV.
📝 Transcript Processing: Fetches transcripts using the YouTube Transcript API, with support for Hindi-to-English translation.
🤖 AI Summarization: Leverages the DistilBART transformer model for efficient, high-quality transcript summarization.
📄 PDF Generation: Creates clean, structured PDFs with screenshots and summaries using ReportLab.


🛠️ Installation
1. Clone the Repository
git clone https://github.com/Shyam-Singh-Bhargaw/youtube-lecture-summarizer.git
cd youtube-lecture-summarizer

2. Install Dependencies
pip install -r requirements.txt


Note: If you're using Google Colab, the notebook includes a cell to install dependencies automatically.


🚀 Usage
Get started with summarizing your lectures in just a few steps:
1. Open the Notebook in Colab
Click the button below to launch the notebook directly in Google Colab:  
2. Run the Notebook

Follow the prompts to enter the YouTube lecture URL and a desired PDF filename.
The script will:

Extract frames and transcripts.  
Generate AI-powered summaries.  
Create a PDF with a visual timeline.




📦 Dependencies
The project depends on the following Python packages, listed in requirements.txt:

youtube-transcript-api - For fetching YouTube transcripts.
transformers - For AI-powered summarization.
torch - For running the transformer model.
reportlab - For generating PDFs.
yt-dlp - For downloading YouTube videos.
opencv-python - For extracting video frames.

Install them with:
pip install -r requirements.txt
