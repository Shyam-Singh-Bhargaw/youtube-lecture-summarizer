📚 YouTube Lecture Summarizer with Visual Timeline 🚀
   
Transform lengthy YouTube lectures into concise PDF summaries with visual timelines! This tool extracts key frames every 20 seconds, summarizes transcripts using advanced AI models, and compiles everything into a beautifully formatted PDF. Perfect for students, educators, and lifelong learners who want to study smarter. 🎓

🌟 Features

📹 Video Download: Seamlessly downloads YouTube lectures using yt-dlp.
🖼️ Frame Extraction: Captures screenshots every 20 seconds with OpenCV.
📝 Transcript Processing: Fetches transcripts via the YouTube Transcript API, with support for Hindi-to-English translation.
🤖 AI Summarization: Summarizes transcript segments using the DistilBART transformer model with efficient batch processing.
📄 PDF Generation: Creates a clean PDF with screenshots and summaries using ReportLab.


🛠️ Installation
Get started in just a few steps! Follow the instructions below to set up the project on your local machine or in Google Colab.

Clone the Repository:
git clone https://github.com/Shyam-Singh-Bhargaw/youtube-lecture-summarizer.git
cd youtube-lecture-summarizer


Install Dependencies:
pip install -r requirements.txt


Note: If you're using Colab, the notebook includes a cell to install dependencies automatically.

📦 Dependencies
The project relies on the following Python packages, listed in requirements.txt:

youtube-transcript-api - For fetching YouTube transcripts.
transformers - For AI-powered summarization.
torch - For running the transformer model.
reportlab - For generating PDFs.
yt-dlp - For downloading YouTube videos.
opencv-python - For extracting video frames.

Install them easily with:
pip install -r requirements.txt
